# Beymert Tuhafiye Website

Beymert Tuhafiye için e-ticaret içermeyen, mobil öncelikli parti malzemeleri tanıtım ve katalog sitesi.

## Hedef

Ziyaretçilerin ürün kategorilerini ve parti konseptlerini keşfetmesini, galeri üzerinden fikir edinmesini ve mağaza / WhatsApp / telefon kanallarına kolayca ulaşmasını sağlamak.

## Başlangıç stack'i

- Next.js 16 + App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- GSAP + ScrollTrigger
- Lenis

shadcn/ui ile seçilmiş Skiper UI, Magic UI ve Aceternity bileşenleri ihtiyaç oldukça projeye kaynak kod olarak eklenecek.

## Kapsam

- Ana sayfa
- Ürünler ve ürün detayları
- Kategoriler
- Konseptler
- Galeri
- Hakkımızda
- İletişim / mağaza bilgileri
- WhatsApp yönlendirmeleri

Sepet, ödeme ve kullanıcı üyeliği bu projenin kapsamında değildir.

## Geliştirme

```bash
pnpm install
pnpm dev
```

Kalite kontrolleri:

```bash
pnpm lint
pnpm typecheck
pnpm build
```
